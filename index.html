Google OAuth 設定教學

  1. 為何在預覽畫面會失敗？
    Google 基於安全考量，拒絕了目前隨機變動的預覽網址。要能正常使用，必須將程式放在固定的網域。
  2. 解決方案 A：個人電腦使用
    將程式碼存為 .html 檔，並用 VS Code 的 Live Server 開啟（網址通常是 http://localhost:5500）。
  3. 解決方案 B：發布到 GitHub
    將程式推送到 GitHub 並開啟 Pages 取得網址 (例如 https://您的帳號.github.io/，注意結尾不可有斜線)。
  4. 註冊網址
    前往 GCP Console -> OAuth 同意畫面 -> 建立憑證。在「已授權的 JavaScript 來源」填入上述取得的網址，儲存後即可順利登入！
  5. 如何取得 Sheet ID?
    若系統未自動抓取，請打開您的 Google 試算表，複製網址中 /d/ 與 /edit 之間的字串。
